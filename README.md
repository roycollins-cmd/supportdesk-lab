# supportdesk-lab

## IT Support Home Lab 
A practical IT support laboratory simulating the IT environment of a small business.

This project demonstrates practical skills in: 

- Windows Administration
- Active Directory
- User and group management
- Networking
- DNS and DHCP
- Powershell
- Troubleshooting
- Help desk ticket management
- Technical documentation
- Microsoft 365 administration
- Basic Cybersecurity

## Environment 
The simulated company contains approximately 25 users across several departments: 
- Finance
- Sales
- Human Resources
- Management
- IT

## Lab Objectives 

the purpose of this lab is to develop practical experience diagnosing and resolving common IT support problems. 

The lab includes: 

1. Windows client administration
2. Windows Server
3. Active Directory
4. DNS
5. DHCP
6. Group policy
7. File permissions
8. Network troubleshooting
9. Powershell automation
10. Help desk ticket management
11. Technical documentation
12. Security incident handling

## Troubleshooting Methodology 

Each Support issue is investigated using the following process: 
1. Identify the problem
2. Gather information
3. Reproduce the issue
4. Diagnose the root cause
5. Apply a solution
6. Verify the solution
7. Document the resolution
8. Identify preventative measures
